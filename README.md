# Resustyle

I created this app because I wanted a way to make my resume/CV more modern and fresh.
I also wanted to be able to easily try different layouts for my resume on the fly.
The app has JSON format that can be imported/exported for reuse. On import it pulls data from
the JSON file and then displays it in different templates you can choose from to give your resume/CV
the look you prefer. This project was created in collaboration with
two excellent engineers byronxc and greggydeggy. The project has been abandoned and there are plenty 
of offerings online now for this kind of service (paid services mostly). I'm keeping it on by GitHub as a demo of a personal project
where I worked with other engineers and also as a demo of using React for Web apps.

# Tech Used

React, i18next for multi-lingual support, FontAwesome react, Microsoft Fabric Components... more to come
